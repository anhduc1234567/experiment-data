# Kết quả chính trên bộ 421 câu

Bốn thư mục tương ứng WF2–5. Mỗi workflow có 421 kết quả, cùng case_id với
02_question_sets/questions_421.jsonl. results.json và metrics.csv đã lọc theo bộ này;
RAGAS input/index cùng thứ tự. cases/ giữ nguyên bằng chứng, trace, thời gian và
usage của các câu được giữ. export-manifest.json mô tả bản xuất theo ID.
Thông số thực nghiệm được ghi trong kết quả; source code không nằm trong gói dữ liệu.
